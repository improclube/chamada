# Lista de Chamada Improclube

Cadastro de turmas e alunos, chamada por data, faltas automáticas, pesquisa de aulas e backups.

Novas aulas começam com todos os alunos presentes. O professor desmarca quem faltou e salva a chamada. Aulas já salvas preservam as presenças e faltas registradas.

Ao abrir o site, informe um token de acesso válido na tela Conectar ao GitHub. Não é a senha da conta GitHub. O token permanece somente na memória da página, é enviado apenas à API GitHub e não é incluído em config.js, no repositório ou no armazenamento do navegador.

Os registros ficam em chamada.json no repositório privado improclube/chamada-dados, branch main. O site pode ser hospedado somente no GitHub Pages.

Leia ATIVAR-GITHUB.md para publicar e configurar. Use um token novo se o anterior tiver sido revogado.

A leitura, gravação, login, erros e conflitos foram verificados com GitHub simulado. Nenhuma credencial foi testada contra o GitHub real nesta entrega.
